## 🚀 Inicio Rápido

### 1. Instalación

```bash

```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

### 3. Producción

```bash

npm run build

# Iniciar servidor de producción
npm start
```

### Cambiar Colores

Edita las variables en `app/globals.css`:

```css

  --primary-color: #3b82f6;     /* Azul principal */
  --secondary-color: #8b5cf6;   /* Púrpura secundario */
  --accent: #06b6d4;             /* Color de acento */
  --dark-bg: #0f172a;            /* Fondo oscuro */
}
```

## ⚡ Quick Tips

### Actualizar Información Personal
1. Abre `app/page.js`
2. Busca las secciones comentadas (ej: `{/* Hero Section */}`)
3. Actualiza texto, enlaces y datos

### Agregar Foto de Perfil
1. Coloca tu foto en `public/images/profile.jpg`
2. En `app/page.js`, busca `about-image`
3. Reemplaza el placeholder con un tag `<img>`

### Cambiar Email
Busca y reemplaza `contacto@itpartner.com.ar` en:
- Hero section
- Contact section  
- Footer

### Agregar Nuevos Proyectos
Duplica un componente `<ProjectCard />` y personaliza:
```javascript
<ProjectCard
  icon="fa-tu-icono"
  title="Nombre del Proyecto"
  description="Descripción..."
  technologies={['Tech1', 'Tech2']}
/>
```
